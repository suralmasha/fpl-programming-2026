# Файл pyproject.toml

`pyproject.toml` хранит описание проекта, зависимости и настройки инструментов.
**Файл должен лежать в корне проекта**.
`pyproject.toml` в этой папке - пример того, как он может выглядеть.

## Основные секции

| Секция                         | Назначение                                       |
|--------------------------------|--------------------------------------------------|
| `[project]`                    | Название, версия, описание проекта и зависимости |
| `[dependency-groups]`          | Группы зависимостей для разработки и тестов      |
| `[build-system]`               | Инструмент и зависимости для сборки пакета       |
| `[tool.ruff]` и его подсекции  | Настройки линтера и форматтера Ruff              |
| `[tool.black]`, `[tool.isort]` | Настройки Black и isort                          |
| `[tool.mypy]`                  | Настройки проверки типов                         |
| `[tool.pytest.ini_options]`    | Настройки pytest                                 |

В TOML квадратные скобки обозначают секцию, `ключ = значение` задает параметр,
а `#` начинает комментарий. Пояснения к параметрам есть в самом примере.

## Работа с uv

```shell
uv add requests
uv add --dev ruff
uv sync
```

`uv add` добавляет зависимость в `pyproject.toml`, `--dev` относит ее
к инструментам разработки, `uv sync` устанавливает зависимости.
Конкретные версии зависимостей uv фиксирует в `uv.lock`.

Подробнее о менеджере зависимостей - в [инструкции uv](uv_usage.md).

Настройки инструментов в `[tool.*]` меняют их поведение, но не запускают их.
