# Проверки перед коммитом с pre-commit

pre-commit автоматически запускает проверки перед коммитом.
**Файл `.pre-commit-config.yaml` должен лежать в корне Git-репозитория**,
рядом с `dirty_code/pyproject.toml` и Makefile. Конфиг в этой папке - пример с Ruff.

## Подключение

Нужны Git и uv. Команды одинаковы на macOS и Windows (PowerShell или Git Bash).
Выполняйте их из корня своего проекта.

```shell
uv tool install pre-commit==4.7.0
pre-commit install
pre-commit run --all-files
```

`install` подключает Git-хук в локальном репозитории.
`run --all-files` запускает проверки для всех файлов, добавленных в Git.
При обычном коммите проверяются подготовленные к нему файлы.

## Что означает конфиг

| Параметр   | Назначение                 |
|------------|----------------------------|
| `repos`    | Список источников проверок |
| `repo`     | Адрес репозитория с хуками |
| `rev`      | Версия проверок            |
| `hooks`    | Проверки в порядке запуска |
| `id`       | Имя хука                   |
| `args`     | Аргументы команды          |
| `types_or` | Типы проверяемых файлов    |

В примере `ruff-check` с `--fix` исправляет доступные нарушения,
затем `ruff-format` форматирует код. Настройки Ruff находятся в `dirty_code/pyproject.toml`.
Используйте один форматтер: Ruff или Black.

Если проверка изменила файлы, просмотрите изменения, снова добавьте их
в Git и повторите проверку. Ошибки, которые не исправляются автоматически,
нужно исправить вручную.

## Примеры нечистого кода

В `dirty_code/formatting.py` есть нарушения оформления и импортов.
В `dirty_code/logic.py` используется неопределенная переменная `delivery_cost`:
линтер найдет ее, а форматтер не исправит.

Из корня репозитория курса можно отдельно запустить линтер и посмотреть
предлагаемое форматирование:

```shell
uvx --from ruff==0.17.3 ruff check standartisation/dirty_code/
uvx --from ruff==0.17.3 ruff format --diff standartisation/dirty_code/
```

Эти команды не меняют файлы. Для исправлений используются `ruff check --fix`
и `ruff format` без `--diff`.
