# Использование Makefile

Makefile хранит команды для повторяющихся действий.
**Файл должен лежать в корне проекта**, рядом с `dirty_code/pyproject.toml` и README.
Makefile в этой папке - пример набора команд для разработки на uv.

## Установка make

На macOS make входит в инструменты разработчика Apple:

```sh
xcode-select --install
```

На Windows установите [MSYS2](https://www.msys2.org/), откройте терминал
MSYS2 UCRT64 и выполните:

```sh
pacman -S make
```

На Windows запускайте make из этого терминала. Команды `make --version`
и `uv --version` должны быть доступны в нем.

## Как записать команду

```makefile
.PHONY: lint

lint:
	uv run ruff check .
```

`lint` - имя цели, строка под ним - команда. Перед командой нужна табуляция.
`.PHONY` указывает, что цель обозначает действие, а не файл.
Теперь проверка запускается через `make lint`.

Команды добавляют постепенно: сначала установку зависимостей и запуск программы,
затем проверки, форматирование и тесты.

## Команды примера

Запускайте из корня своего проекта; синтаксис одинаков на macOS и Windows.

| Команда                          | Действие                                                            |
|----------------------------------|---------------------------------------------------------------------|
| `make help`                      | Показать список команд                                              |
| `make sync`                      | Установить зависимости, включая группу `test`                       |
| `make add PACKAGE=requests`      | Добавить зависимость приложения                                     |
| `make add-dev PACKAGE=ruff`      | Добавить инструмент разработки                                      |
| `make remove PACKAGE=requests`   | Удалить зависимость приложения                                      |
| `make lock`                      | Обновить lock-файл                                                  |
| `make update`                    | Обновить версии в пределах ограничений `dirty_code/pyproject.toml`  |
| `make run ARGS="python main.py"` | Запустить программу                                                 |
| `make test`                      | Запустить тесты из группы `test`                                    |
| `make lint`                      | Проверить код через Ruff                                            |
| `make format`                    | Отсортировать импорты через isort и отформатировать код через Black |
| `make typecheck`                 | Проверить типы в `src/`                                             |
| `make check`                     | Выполнить проверки без исправления исходников                       |
| `make build`                     | Собрать wheel и исходный архив                                      |
| `make wheel` / `make sdist`      | Собрать один из форматов                                            |
| `make check-dist`                | Проверить метаданные дистрибутивов                                  |
| `make publish`                   | Опубликовать пакет на PyPI                                          |

Пути, зависимости и команды в Makefile выбирают под свой проект.
Для публикации нужен токен, описанный в [инструкции uv](../packaging/uv_usage.md).
Если форматированием занимается Ruff, используйте `uv run ruff format .`
вместо Black, а `uv run ruff check --select I --fix .` - вместо isort.
