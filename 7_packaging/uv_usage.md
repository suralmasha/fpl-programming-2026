# Сборка и публикация пакета с uv

Нужны [uv](https://docs.astral.sh/uv/getting-started/installation/)
и проект с настроенным `[build-system]` в `pyproject.toml`.
Общие команды одинаковы для macOS (zsh/bash) и Windows (PowerShell).

## Создание пакета

```shell
uv init --lib mypackage
cd mypackage
```

uv создаст `pyproject.toml`, настроит сборку и подготовит каталог
`src/mypackage/`. Для существующего пакета этот шаг не нужен.

## Сборка

Из корня пакета выполните:

```shell
uv build
```

В `dist/` появятся wheel (`.whl`) и исходный архив (`.tar.gz`).
Для `mypackage` версии `0.1.0`:

```text
dist/
    mypackage-0.1.0-py3-none-any.whl
    mypackage-0.1.0.tar.gz
```

- Wheel устанавливается без сборки. Метка `py3-none-any` обозначает пакет
  для Python 3 без привязки к ABI и платформе; другие wheel могут иметь ограничения.
- Исходный архив требует сборки при установке и может требовать компилятор
  и системные библиотеки. Универсальная совместимость не гарантируется.

## Установка

В другом uv-проекте добавьте собранный wheel как зависимость:

```shell
uv add "../mypackage/dist/mypackage-0.1.0-py3-none-any.whl"
```

Замените путь на фактический. Кавычки нужны для путей с пробелами;
прямые слеши в этом пути подходят обеим системам.
Имя импортируемого модуля определяется исходниками и может отличаться
от имени дистрибутива. Для модуля `mypackage`:

```python
import mypackage
```

## Публикация на PyPI

Нужны учетная запись на [PyPI](https://pypi.org/) и API-токен с правом публикации.
Замените имя проекта на уникальное в `pyproject.toml` и пересоберите пакет.
По умолчанию `uv_build` выводит имя модуля из имени проекта: если модуль остается
`mypackage`, добавьте `[tool.uv.build-backend]` с `module-name = 'mypackage'`.
Задайте токен в текущем терминале, заменив пример своим значением.
Не сохраняйте токен в файлах проекта и учитывайте историю команд терминала.

macOS (zsh/bash):

```sh
export UV_PUBLISH_TOKEN="pypi-ВАШ_ТОКЕН"
```

Windows (PowerShell):

```powershell
$env:UV_PUBLISH_TOKEN = "pypi-ВАШ_ТОКЕН"
```

После сборки загрузите дистрибутивы:

```shell
uv publish
```

По умолчанию uv загружает дистрибутивы из `dist/`. Перед публикацией убедитесь,
что там только нужные файлы. Пакет станет общедоступным;
повторно загрузить тот же файл нельзя.

Установка опубликованного пакета в другом uv-проекте:

```shell
uv add mypackage
```

В команде установки указывайте выбранное вами имя проекта на PyPI.
Для проверки импорта в проекте-потребителе: `uv run python -c "import mypackage"`.

Источник: [сборка и публикация пакетов](https://docs.astral.sh/uv/guides/package/).
