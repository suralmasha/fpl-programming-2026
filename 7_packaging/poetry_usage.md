# Сборка и публикация пакета с Poetry

Нужны Python, [Poetry 2.x](https://python-poetry.org/docs/#installation)
и настроенный `pyproject.toml` в режиме пакета (`package-mode = true`, по умолчанию).
Команды одинаковы для macOS (zsh/bash) и Windows (PowerShell);
выполняйте их из корня своего пакета.

## Сборка

```shell
poetry build
```

В `dist/` появятся wheel (`.whl`) и исходный архив (`.tar.gz`).
Имена определяются названием и версией проекта в `pyproject.toml`.
Например, для проекта `mypackage` версии `0.1.0`:

```text
dist/
    mypackage-0.1.0-py3-none-any.whl
    mypackage-0.1.0.tar.gz
```

- Wheel устанавливается без сборки. Метка `py3-none-any` обозначает пакет
  для Python 3 без привязки к ABI и платформе; другие wheel могут иметь ограничения.
- Исходный архив требует сборки при установке и может требовать компилятор
  и системные библиотеки. Универсальная совместимость не гарантируется.

## Установка

В другом Poetry-проекте добавьте собранный wheel как зависимость:

```shell
poetry add "../mypackage/dist/mypackage-0.1.0-py3-none-any.whl"
```

Замените путь на фактический. Кавычки нужны для путей с пробелами;
прямые слеши в этом пути подходят обеим системам.
Имя импортируемого модуля определяется исходниками и может отличаться
от имени дистрибутива. Для модуля `mypackage`:

```python
import mypackage
```

## Публикация на PyPI

Нужны учетная запись на [PyPI](https://pypi.org/) и API-токен с правом публикации.
Перед публикацией замените имя проекта `mypackage` на уникальное в `pyproject.toml`
и пересоберите пакет. Имя модуля в `packages` менять при этом не обязательно.
В `dist/` оставьте только дистрибутивы для публикации.
Сохраните токен, заменив пример своим значением (команда одинакова для обеих систем):

```shell
poetry config pypi-token.pypi "pypi-ВАШ_ТОКЕН"
```

Команда без значения токена не запрашивает его интерактивно.
Не сохраняйте токен в проекте; учитывайте, что он может попасть в историю терминала.

После сборки загрузите дистрибутивы:

```shell
poetry publish
```

Poetry сам выбирает файлы текущей версии из `dist/`; передавать `dist/*` не нужно.
Публикация делает пакет общедоступным; повторно загрузить тот же файл нельзя.

Установка опубликованного пакета в другом Poetry-проекте:

```shell
poetry add mypackage
```

В команде установки указывайте выбранное вами имя проекта на PyPI.
Для пробной установки без активации используйте `poetry run python -c "import mypackage"`.

Источники: [команды Poetry](https://python-poetry.org/docs/cli/),
[настройка токенов](https://python-poetry.org/docs/repositories/#configuring-credentials).
